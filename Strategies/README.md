# Frontier TradeLight — `Strategies/`

All of the project's code lives in this folder. See the
[project README](../README.md) for the full documentation: architecture,
setup, every tab, the CLI, and data files.

Quick start (from this directory, after the setup steps in the root README):

```bash
npm run dev
```

This starts the India backend (`Default/`, port 8000), the US backend
(`US/`, port 8001) and the React frontend (http://localhost:5173).
