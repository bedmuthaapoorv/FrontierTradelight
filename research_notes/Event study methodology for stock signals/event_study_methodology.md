# Academic Event Study Methodology for Measuring Stock Price Reactions to News Announcements

## What is the standard event study procedure (estimation window, event window, normal-return model, CAR/BHAR computation)?

### Takeaway
The canonical event study procedure — codified first by Fama, Fisher, Jensen & Roll (1969) and later systematized by MacKinlay (1997) and Brown & Warner (1985) — defines an event date, an estimation window (commonly 100–250 trading days, ending before the event window) used to fit a "normal return" model, and a short event window around the announcement; abnormal returns (actual minus model-predicted "normal" return) are computed for each day in the event window, then aggregated across time (Cumulative Abnormal Return, CAR) and/or across firms (Average Abnormal Return, AAR / Cumulative Average Abnormal Return, CAAR). Long-horizon studies instead use Buy-and-Hold Abnormal Returns (BHAR) against a matched benchmark, because compounding daily CARs is not equivalent to actual holding-period returns.

### Cited Findings
- MacKinlay's 1997 survey ("Event Studies in Economics and Finance," *Journal of Economic Literature* 35:13-39) lays out the general procedure: define the event, identify the event window, measure abnormal returns, then perform statistical tests and analysis — [Semantic Scholar](https://www.semanticscholar.org/paper/Event-Studies-in-Economics-and-Finance-Mackinlay/61d66e74e0d6973baf01ced1ddc27bc182c88bce); [EconPapers](https://econpapers.repec.org/RePEc:aea:jeclit:v:35:y:1997:i:1:p:13-39)
- The most common normal-return model is the **market model** — a firm's return regressed on a market index return over the estimation window (yielding alpha, beta, and residual variance/sigma), typically fit over an estimation window "sized 120 days" prior to the event — [WebSearch summary of MacKinlay (1997)](https://www.semanticscholar.org/paper/Event-Studies-in-Economics-and-Finance-Mackinlay/61d66e74e0d6973baf01ced1ddc27bc182c88bce)
- The canonical reference estimation-window length used in practice is 250 trading days, and results "are not sensitive to varying estimation-window lengths as long as the window exceeds about 100 days" — [EventStudyTools Application Blueprint](https://www.eventstudytools.com/event-study-application-blueprint)
- The six-step practical workflow: (1) identify the event date, (2) select the sample and screen for confounding events, (3) choose a normal-return model, (4) set estimation- and event-window lengths, (5) estimate returns and compute abnormal-return metrics, (6) conduct significance testing — [EventStudyTools Application Blueprint](https://www.eventstudytools.com/event-study-application-blueprint)
- Alternative normal-return models include the market-adjusted model (used when a clean, uncontaminated estimation window isn't practical — assumes alpha=0, beta=1) and the CAPM; for long-horizon studies, multi-factor models (e.g., Fama-French size/value/momentum factors) are used "where size, value, or momentum exposures could bias results" — [EventStudyTools Application Blueprint](https://www.eventstudytools.com/event-study-application-blueprint); [Wikipedia: Event study](https://en.wikipedia.org/wiki/Event_study)
- Abnormal returns aggregate into three standard statistics: **AAR** (average abnormal return across firms on a given event day), **CAR** (cumulative abnormal return across days for one firm), and **CAAR** (cumulative average abnormal return — averaged across firms and cumulated across days) — [EventStudyTools Application Blueprint](https://www.eventstudytools.com/event-study-application-blueprint)
- Fama, Fisher, Jensen & Roll (1969), "The Adjustment of Stock Prices to New Information," *International Economic Review* 10:1-21, is considered the first true event study; it introduced the first explicit control for the market factor (a precursor to Fama-French models) and the first direct test of market efficiency, using stock-split announcements as the event and CRSP price data — [Iang Gow's FAR book chapter on FFJR](https://iangow.github.io/far_book/ffjr.html); [ResearchGate: Ball, "FFJR: Retrospective Comments"](https://www.researchgate.net/publication/272305362_Fama_Fisher_Jensen_and_Roll_1969_Retrospective_Comments)
- Brown & Warner (1985), "Using Daily Stock Returns: The Case of Event Studies," *Journal of Financial Economics* 14(1):3-31, examined how the specific statistical properties of daily (rather than monthly) return data affect event-study test procedures, and found that "daily data generally present few difficulties for event studies, and standard procedures are typically well-specified even when special daily data characteristics are ignored" — [Colorado working paper PDF](https://leeds-faculty.colorado.edu/bhagat/brownwarner1985.pdf); [ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/0304405X8590042X)
- For long-horizon studies, Barber & Lyon (and Lyon, Barber & Tsai 1999, "Improved Methods for Tests of Long-Run Abnormal Stock Returns," *Journal of Finance*) show BHAR is preferred over compounded CAR because BHARs "precisely measure investor experience," but long-horizon BHARs are positively skewed, which biases standard t-statistics negatively; carefully constructed reference portfolios or matched control firms are used to eliminate new-listing and rebalancing biases, with inference based on a skewness-adjusted t-statistic or empirical p-values — [Stern NYU PDF of Lyon-Barber-Tsai (1999)](https://pages.stern.nyu.edu/~eofek/PhD/papers/LBT_Improved_JF.pdf); [SSRN abstract](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7197)
- Kothari & Warner (2007), "Econometrics of Event Studies," Ch. 1 in the *Handbook of Corporate Finance: Empirical Corporate Finance* (pp. 3-36), conclude that "short-horizon methods are quite reliable, while long-horizon methods have improved but serious limitations remain," and that method properties can vary by calendar period and by sample firm characteristics such as volatility — [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=608601); [ScienceDirect chapter](https://www.sciencedirect.com/science/chapter/edited-volume/abs/pii/B9780444532657500159)

### Inferences
- For a systematic signal reacting to discrete press-release-style events (e.g., defense-contract wins), a short-horizon design (market or market-adjusted model, event window of a few days, CAR-based aggregation) is the academically best-supported approach — it is the regime where event-study methodology is most reliable and least sensitive to modeling choices.
- Given that contract-announcement signals will likely be evaluated per-firm or on modest samples (not hundreds of pooled firm-events), the choice between market model and market-adjusted model matters less than getting the estimation window right (100+ trading days, ending well before the event window, screened for confounding events).
- BHAR/long-horizon methodology is largely irrelevant to a short-reaction trading signal; it matters only if one wants to also measure a 6-12 month post-announcement drift effect.

### Gaps
- None identified for this question at the depth needed; the exact regression specification (log returns vs. simple returns, single-index vs. multi-index market model) is implementation detail not resolved uniformly across primary sources found.

## How do researchers choose the event window length, and is there a principled way to pick it rather than an arbitrary one?

### Takeaway
Event window choice trades off two competing risks — too short a window misses slow information diffusion/leakage, too long a window risks contamination from confounding events and added noise — and while pooled multi-firm studies can rely on the Law of Large Numbers to average out this arbitrariness, single-security or small-sample studies benefit from a principled, data-driven window (e.g., based on continuing abnormal price movement or the size of the news shock) rather than a fixed arbitrary window.

### Cited Findings
- "On one hand, information leakage and longer information processing periods favor longer event windows, and on the other hand, confounding events suggest shorter event windows" — [WebSearch synthesis citing eventstudytools.com/MASEconomics](https://maseconomics.com/event-study-methodology-explained/)
- "When standardizing event window length across observations, the errors from having too long or short an event window should have a small impact on the average by the Law of Large Numbers" — but this justification is for pooled, large-sample studies, not single-security studies — [Krivin, Patton, Rose & Tabak (2003), "Determination of the Appropriate Event Window Length in Individual Stock Event Studies," NERA Economic Consulting](https://www.nera.com/content/dam/nera/publications/archive1/6394.pdf); [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=466161)
- Krivin, Patton, Rose & Tabak (2003) explicitly test rules for choosing event-window length for a *single or small number of* securities, since a fixed-length window "may be less appropriate for studies that focus on just a few securities." They find that rules based on continuing price movement (i.e., extending the window until abnormal returns stop accumulating) yield window lengths that correlate with the "size" of the news as measured by the magnitude of earnings surprises, whereas a rule based on abnormally high volume does not have this desirable property — [NERA PDF](https://www.nera.com/content/dam/nera/publications/archive1/6394.pdf); [ResearchGate](https://www.researchgate.net/publication/228236118_Determination_of_the_Appropriate_Event_Window_Length_in_Individual_Stock_Event_Studies)
- Typical event windows in the literature range from 1 to 11 trading days, with a symmetric 5-day window (e.g., [-2,+2]) being most common, balancing leakage concerns against contamination risk — [EventStudyTools Application Blueprint](https://www.eventstudytools.com/event-study-application-blueprint)
- Short-horizon event studies (days, not months) are "among the more dependable designs in empirical finance, because over a few days the choice of normal-return model barely matters" — [WebSearch synthesis, bookdown.org "A Guide on Data Analysis," Ch. 39 Event Studies](https://bookdown.org/mike/data_analysis/sec-event-studies.html)
- During periods of market-wide high volatility (e.g., 2008 financial crisis), "too many companies tend to show significantly abnormal returns," which complicates identifying genuine event-driven abnormal performance and argues for tighter windows and volatility-aware significance tests during turbulent regimes — [Wikipedia: Event study](https://en.wikipedia.org/wiki/Event_study)

### Inferences
- For a defense-contract/press-release signal, the principled approach is: (1) start with a short, standard symmetric window (e.g. [-1,+1] or [0,+2]) as the baseline for pooled statistical validation across many historical announcements, since the Law of Large Numbers argument justifies a fixed window at the portfolio level; (2) optionally validate window length per-event using a continuing-abnormal-return rule (extend window until AR decays back to insignificance) as in Krivin et al. (2003), especially if the signal is meant to size positions per individual announcement rather than just validate the strategy in aggregate.
- Because the underlying data-generating events here (contract awards) are discrete, scheduled-release, public announcements (not slow-diffusing information like an M&A rumor), the leakage risk is lower than for many corporate-event event studies, which favors a shorter window and reduces the case for extending into [0,+20]-day windows except to study post-announcement drift specifically.

### Gaps
- No source found that gives a single universally "correct" window length; the literature consensus is that window choice is a bias/noise tradeoff decision, not a solved parameter — this should be stated plainly to whoever is building the signal, rather than presenting a single number as authoritative.

## What statistical tests determine whether an abnormal return is significant, and what sample sizes are sufficient for reliable inference?

### Takeaway
The standard toolkit runs from simple parametric t-tests through the Patell (1976) standardized-residual Z-test and the Boehmer-Musumeci-Poulsen (1991, "BMP") standardized cross-sectional t-test (now the default for short-window studies because it self-corrects for event-induced variance increases), to nonparametric rank/sign tests for non-normal or small samples, with Kolari-Pynnonen (2010) adjustments applied whenever event dates cluster in calendar time; statistical power depends heavily on how concentrated the abnormal return is in time — a handful of firms can detect a large, single-day effect, but detecting the same cumulative effect spread over months requires samples in the hundreds.

### Cited Findings
- Parametric tests (assume approximate normality): the plain cross-sectional t-test, the Patell Z (standardized residual) test, and the BMP standardized cross-sectional t-test; nonparametric tests (no normality assumption): sign tests, rank tests, and the generalized sign test — [EventStudyTools: Significance Tests](https://www.eventstudytools.com/significance-tests)
- The Patell Z test divides each firm's abnormal return by its forecast-error-corrected standard deviation (accounting for base residual variance, estimation error, and forecast extrapolation based on the market return's distance from its estimation-window mean) before aggregating across firms — but it assumes the event itself does not increase return volatility, and "over-rejects when announcement-day variance spikes" — [EventStudyTools: Significance Tests](https://www.eventstudytools.com/significance-tests)
- The BMP test extends Patell by additionally dividing standardized returns by their event-day cross-sectional standard deviation, so "the denominator widens automatically when the event makes everyone volatile," making it robust to event-induced variance increases; it is now "the standard parametric default for short-window event studies" — [EventStudyTools: Significance Tests](https://www.eventstudytools.com/significance-tests)
- Kolari-Pynnonen (2010) adjusted variants of Patell and BMP deflate the test statistic to correct for cross-sectional correlation when event dates cluster; the adjustment factor is √[(1 − r̄)/(1 + (N−1)r̄)] where r̄ is the average pairwise cross-sectional correlation of abnormal returns — with even a small r̄ = 0.02 and N = 100 firms, the true standard error is roughly 1.4x the naive (uncorrected) estimate — [EventStudyTools: Significance Tests](https://www.eventstudytools.com/significance-tests)
- Nonparametric alternatives: the Corrado rank test (converts abnormal returns to within-firm ranks, resistant to outliers but less powerful over multi-day windows); the generalized sign test (compares the fraction of positive abnormal returns in the event sample to the sample's own historical positive fraction, rather than assuming 50%, to be robust to natural drift); and the generalized rank T-test, described as handling cross-sectional correlation, serial correlation, and event-induced volatility simultaneously and the "most robust" option — [EventStudyTools: Significance Tests](https://www.eventstudytools.com/significance-tests)
- Recommended practical rule: "Run one parametric and one non-parametric test that target the threats your sample actually faces, report both, and treat agreement as the real evidence" — [EventStudyTools: Significance Tests](https://www.eventstudytools.com/significance-tests)
- On sample size and power: for a 10% abnormal-performance effect concentrated in a single day, a sample of only 6 stocks can detect it with 100% power; but for the same cumulative 10% effect spread over six months, a sample of 200 is needed to detect it even 65% of the time — [ResearchGate: "Statistical Power for an Event Study" discussion thread](https://www.researchgate.net/post/Statistical_Power_for_an_Event_Study)
- Empirical return distributions for small groups (5-10 securities) are highly non-normal for both mean excess returns and test statistics, whereas groups of 20-50 securities have distributions close to normal — larger samples both normalize the test statistic distribution and increase power to detect a given abnormal-return magnitude — [ResearchGate discussion, citing event-study Monte Carlo literature](https://www.researchgate.net/post/Statistical_Power_for_an_Event_Study)
- Statistical power is inversely related to sample security return variance (noisier returns make a given signal harder to detect) and standard event-study methods can produce false-positive abnormal returns especially in samples of small firms or firms with low prior returns — [ResearchGate discussion](https://www.researchgate.net/post/Statistical_Power_for_an_Event_Study)

### Inferences
- Because the concentrated, single-day nature of a contract-announcement price reaction is closer to the "6 stocks, 100% power for single-day effect" case than the diffuse long-horizon case, even a moderate sample of historical contract-award announcements (dozens, not hundreds) could plausibly support statistically meaningful inference on a short event window — but this should be validated empirically with the actual observed effect size and variance, not assumed.
- Given that contract announcements for the same company/sector may cluster in time (e.g., multiple firms winning tranches of the same government program on the same day, or one firm winning several contracts across a short period), the Kolari-Pynnonen cross-sectional-correlation correction is directly relevant and should not be skipped — naive t-tests will overstate significance in exactly this scenario.
- The BMP test (or its Kolari-Pynnonen-adjusted variant) is the best default significance test for this use case: contract-announcement days plausibly see elevated volatility (event-induced variance), which Patell and plain t-tests do not correct for.

### Gaps
- No specific numeric "minimum sample size" threshold with citation was found (e.g., "N=30 is sufficient") — the literature frames sufficiency in terms of a power calculation given expected effect size and variance, not a fixed rule of thumb, so any such rule of thumb should be treated as an approximation, not an academic finding.

## What known biases/pitfalls affect event studies, and how are they corrected for?

### Takeaway
The main threats to valid inference are event-date clustering (violates the independence assumption underlying standard tests and shrinks the effective sample size), thin/infrequent trading (introduces bid-ask bounce noise that biases cumulative abnormal returns), event-induced variance changes (invalidates tests calibrated on pre-event volatility), and benchmark/normal-return-model misspecification (especially for long-horizon studies); corrections include cross-sectional-correlation-adjusted test statistics, portfolio-level aggregation of same-day events, trade-to-trade or Scholes-Williams-type beta adjustments for thin trading, standardized cross-sectional (BMP-style) tests for event-induced variance, and control-firm/reference-portfolio matching plus skewness-adjusted or bootstrapped tests for long-horizon benchmark problems.

### Cited Findings
- **Event clustering:** "Standard event study inference assumes abnormal returns are independent across firms. When many firms react to the same event on the same calendar day... the abnormal returns are correlated and the effective sample is far smaller than the number of firms suggests. The standard tests assume independence, so clustering inflates the apparent sample size and understates the standard errors unless the affected firms are treated as one portfolio" — [WebSearch synthesis](https://bookdown.org/mike/data_analysis/sec-event-studies.html)
- The Kolari-Pynnonen (2010) adjustment factor √[(1 − r̄)/(1 + (N−1)r̄)] directly corrects Patell/BMP statistics for this same-day cross-sectional correlation — [EventStudyTools: Significance Tests](https://www.eventstudytools.com/significance-tests)
- **Thin trading:** "Thinly traded stocks tend to bounce between bid and ask prices in patterns that look like genuine return innovations. When these microstructural jumps are aggregated over a multi-day event window, the cumulative abnormal return inherits a small but systematic upward bias" — [WebSearch synthesis](https://maseconomics.com/event-study-methodology-explained/)
- **Event-induced variance:** the Patell Z test "assumes the event does not increase return volatility" and "over-rejects when announcement-day variance spikes"; the BMP test was specifically designed to fix this by re-scaling by the event-day cross-sectional standard deviation — [EventStudyTools: Significance Tests](https://www.eventstudytools.com/significance-tests)
- **Confounding events:** the standard six-step workflow explicitly calls for screening "both the estimation and event windows for unrelated material news that could bias parameter estimates or contaminate the isolated event effect" — [EventStudyTools Application Blueprint](https://www.eventstudytools.com/event-study-application-blueprint)
- **Benchmark/model misspecification (long-horizon):** Barber & Lyon and Lyon-Barber-Tsai (1999) show long-horizon BHARs are positively skewed, which negatively biases standard t-statistics; their recommended fix is to compute BHAR against carefully constructed reference portfolios or matched control firms (to eliminate new-listing and rebalancing biases) and use a skewness-adjusted t-statistic or empirically-generated (bootstrapped) p-values — but "misspecification in nonrandom samples is pervasive," meaning even these improved methods don't fully resolve the problem for non-random event samples — [Stern NYU PDF](https://pages.stern.nyu.edu/~eofek/PhD/papers/LBT_Improved_JF.pdf); [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7197)
- Kothari & Warner (2007) note that the reliability properties of event-study methods "can vary by calendar time period and can depend on event sample firm characteristics such as volatility" — implying no single correction is universally sufficient; robustness checks across sub-periods and firm-size/volatility buckets are advisable — [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=608601)
- Brown & Warner (1985) specifically studied daily-data pitfalls and found that (a) daily excess returns show autocorrelation and event-conditional variance changes that can sometimes be exploited/adjusted for, but (b) "tests ignoring cross-sectional dependence can be well-specified and have higher power than tests which account for potential dependence" in many practical settings — i.e., the correction is not always a free lunch and can cost power — [Colorado PDF](https://leeds-faculty.colorado.edu/bhagat/brownwarner1985.pdf); [ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/0304405X8590042X)
- Small-sample / false-positive bias: standard event-study methods "produce statistical biases in grouped samples, with the most significant errors being false positive abnormal returns in samples characterized by small firms and firms with low prior returns" — [ResearchGate discussion](https://www.researchgate.net/post/Statistical_Power_for_an_Event_Study)
- During market-wide turbulence (e.g., 2008 crisis), background volatility inflates the count of "significant" abnormal returns even absent a true firm-specific event effect — a caution against interpreting event-study significance without also benchmarking against a volatility-matched null/placebo period — [Wikipedia: Event study](https://en.wikipedia.org/wiki/Event_study)

### Inferences
- For a defense/government-contract-announcement signal, the most directly relevant biases to guard against are: (1) event clustering — multiple small-cap defense contractors may report contract wins around the same budget-cycle dates, so same-day announcements should be pooled/treated as one correlated cluster rather than independent draws when computing significance; (2) thin trading — many of the smaller-cap names in this space likely trade thinly, so cumulative abnormal returns over multi-day windows should be checked against a trade-to-trade or volume-filtered return series rather than raw close-to-close prices; (3) event-induced variance — announcement-day volatility is very likely elevated versus the estimation window, so a BMP-style (not Patell, not plain t-test) significance test is the appropriate default; (4) confounding events — contract announcements often coincide with routine corporate news flow (results, buybacks) in the same window, which must be explicitly screened out per-event.
- Because this signal is short-horizon by construction (reacting to a press release, not testing multi-month drift), the long-horizon BHAR biases (skewness, new-listing, rebalancing) documented by Barber-Lyon are a secondary concern — relevant only if the strategy also wants to measure or exploit post-announcement drift over weeks/months.

### Gaps
- No source found with hard numeric guidance on "how thin is too thin" for trading-volume screening thresholds in an event study — this is a design choice the strategy builder would need to calibrate empirically against their own investable universe (e.g., a minimum average daily volume/turnover filter), not something available from a general methodology source in the time available for this research pass.
