# Signal Strength Scoring for Corporate Event-Driven Announcements

## What is the classic event-study / CAR methodology (estimation window, event window, market model, abnormal return calculation)?

### Takeaway
The canonical framework (MacKinlay 1997; Kothari & Warner) estimates a stock's "normal" return from a pre-event estimation window using a market model regression, then measures the abnormal return (actual minus predicted) over a short event window around the announcement; abnormal returns are summed into Cumulative Abnormal Returns (CAR) and aggregated across firms as Cumulative Average Abnormal Returns (CAAR), tested for statistical significance against zero.

### Cited Findings
- MacKinlay's framework: "the goal is to measure the effects of an economic event on the value of firms... the effects of an event will be reflected immediately in security prices, so the impact can be measured by examining security prices over a relatively short period" — [MacKinlay 1997, Event Studies in Economics and Finance, JEL 35:13-39](https://econpapers.repec.org/RePEc:aea:jeclit:v:35:y:1997:i:1:p:13-39)
- The most common normal-return model is the "market model," using a pre-event estimation window (commonly ~120 trading days) prior to the event, regressing the firm's returns on a market index to obtain alpha/beta coefficients used to compute expected ("normal") returns; alternatives include CAPM or simple mean/constant-return models — [MacKinlay 1997 summary via search](https://www.semanticscholar.org/paper/Event-Studies-in-Economics-and-Finance-Mackinlay/61d66e74e0d6973baf01ced1ddc27bc182c88bce)
- Abnormal return (AR) = actual ex-post return of the security over the event window minus the "normal" (expected) return over the event window; event studies rest on the semi-strong Efficient Market Hypothesis (prices reflect all public information) — [Event study reaction to government policy, PMC](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9947261/)
- Kothari & Warner's survey "Econometrics of Event Studies" is a standard reference for statistical testing conventions and methodological nuances in event-study design — [Kothari & Warner, BU](https://www.bu.edu/econ/files/2011/01/KothariWarner2.pdf) (note: PDF content could not be parsed by the fetch tool during this research; citation is to the paper's existence/title only, not verified content)
- The event-study method traces its lineage in economics/finance research back to at least 1933 — [MacKinlay 1997 summary](https://www.semanticscholar.org/paper/Event-Studies-in-Economics-and-Finance-Mackinlay/61d66e74e0d6973baf01ced1ddc27bc182c88bce)
- Practical prototyping approach for a signal: rank the cross-section on a surprise variable (SUE, past return, deal type) and compare CAAR trajectories of top vs. bottom groups; abnormal trading volume confirmation increases confidence that a drift is durable rather than noise — [EventStudyTools / general event-study literature search summary](https://www.eventstudytools.com/investment-strategies)

### Inferences
- For an Event Watcher module, the CAR framework implies the score needs (a) an expected/"normal" return baseline (sector or stock beta-adjusted), (b) a defined short event window (e.g., day 0 to day +1 or +3) to measure the immediate reaction, and (c) a longer post-event window to measure drift/decay — these are structurally separate from the "surprise" or "expected impact" scoring itself.
- Because AR/CAR calculation depends on having an estimation-window beta, the composite score for a newly-listed or thinly-traded PSU/defense stock may be less reliable due to noisy beta estimates.

### Gaps
- Full technical content of Kothari & Warner (statistical test specifics — e.g., cross-sectional t-tests, standardized residuals, clustering issues) could not be extracted; the PDF fetch returned only binary/garbled content. Only the paper's role as the standard survey reference could be confirmed.
- Exact standard lengths for estimation windows (e.g., 250 trading days vs. 120) vary by study; only the ~120-day figure was found and is not universally standard — treat as one common convention, not a strict rule.

## How do event studies and practitioner systems combine multiple factors into a single "signal strength" / "expected impact" score?

### Takeaway
No single canonical academic formula exists for a composite "signal strength score"; instead, academic work isolates individual explanatory factors via regression (surprise magnitude, deal/contract size relative to firm size, event-type base rates), while vendors (RavenPack, Bloomberg, AlphaSense) build proprietary composite/event-sentiment indices that blend NLP-derived sentiment, event categorization/taxonomy, historical price-reaction calibration, and novelty/relevance filters into a bounded score.

### Cited Findings
- **RavenPack Composite Sentiment Score (CSS):** a story-level metric from 0–100 (50 = neutral) built by combining multiple sentiment sub-scores (named PEQ, BEE, BMQ, BCA, BAM in RavenPack's documentation); direction is derived from emotionally charged language and comparison to expert ratings of short-term price effects, and magnitude is "empirically calibrated using intraday tick data from approximately 100 large-cap stocks" — [RavenPack, Closer Look at Composite Sentiment Score](https://www.ravenpack.com/research/composite-sentiment-score/)
- **RavenPack Event Sentiment Score (ESS):** an independently built score classifying news into "an extensive list of categories covering more than 330 market moving events," each event category tagged with a sentiment direction — [RavenPack, Composite Sentiment Score research note](https://www.ravenpack.com/research/composite-sentiment-score/); overview also at [RavenPack Event Detection blog](https://www.ravenpack.com/blog/new-ravenpack-analytics-event-detection)
- CSS and ESS are correlated (Pearson r = 32.6%, Spearman rank = 43.7%, both significant at 0.1%) but are not redundant: "when an event is classified as neutral by CSS (CSS=50), with ESS there is a 76.2% chance that such event can be further classified as positive or negative" — meaning event-taxonomy classification (what happened) adds information beyond generic linguistic sentiment (how it was said) — [RavenPack, Composite Sentiment Score](https://www.ravenpack.com/research/composite-sentiment-score/)
- **Bloomberg Event-Driven Feeds / News Analytics:** assigns per-story sentiment scores from -1 (negative) to +1 (positive), 0 neutral; "Market Moving News" indicators estimate short-term market-move probabilities based on story publication; company-level analytics aggregate story-level scores to track continuing developments (i.e., a time-decayed rolling composite, not just a single-story score) — [Bloomberg Professional Services, Trading the news](https://www.bloomberg.com/professional/insights/data/trading-news-use-machine-readable-data-find-alpha/); [Bloomberg, edge from news sentiment data](https://www.bloomberg.com/professional/insights/data/can-get-edge-trading-news-sentiment-data/)
- **AlphaSense:** a proprietary deep-learning sentiment model trained on 10+ years of hand-labeled earnings calls scores documents/transcripts on a -100 to +100 scale (ratio of positive to negative statements), reports 88% agreement with expert human raters on directional classification in backtests, and attaches confidence scores to each AI-generated signal so weighting can be adjusted by confidence — [AlphaSense, How We Calculate Sentiment](https://help.alpha-sense.com/hc/en-us/articles/41711605431059-How-We-Calculate-Sentiment); [AlphaSense sentiment indices launch](https://www.alpha-sense.com/press/alphasense-launches-sentiment-indices-to-identify-early-signals-of-market-confidence-and-risk/)
- Academic practice for isolating factor contributions to abnormal returns uses regression of CAR on candidate explanatory variables (surprise magnitude, relative deal size, firm size, financing type) rather than a single blended "score" — e.g., in M&A studies, "relative size" (transaction value / acquirer market cap) and acquirer size are both regressed against announcement CAR, with acquirer size found to be a "much more dominant driver ... than the relative deal size" in dollar-magnitude terms, while relative deal size still matters for percentage-return magnitude — [Firm size and gains from acquisitions research summary](https://leeds-faculty.colorado.edu/bhagat/acquisitiongains-firmsize.pdf); [Big Moves, Small Gains, Economic Notes 2025](https://onlinelibrary.wiley.com/doi/full/10.1111/ecno.70004)
- Distributional heterogeneity across event types is a documented basis for event-type-conditional scoring: "the distribution of post-event cumulative abnormal returns shows substantial heterogeneity in both dispersion and tail behavior among event types. Risk-related events such as Risk Warning and Violation exhibit wider distributions and heavier tails... routine corporate events including Dividend and Industry announcements show more concentrated distributions around zero" — [Janus-Q: End-to-End Event-Driven Trading via Hierarchical-Gated Reward Modeling](https://arxiv.org/pdf/2602.19919)

### Inferences
- Vendor systems converge on a two-layer design that maps well onto a redesigned Event Watcher: (1) an **event-type/taxonomy classifier** (what kind of event, e.g. "contract win," "earnings beat," analogous to RavenPack's 330+ categories) that carries a prior expected sentiment/impact, and (2) a **linguistic/magnitude sentiment layer** (NLP score of the specific story's language and stated figures) that adjusts around that prior. This is structurally similar to a Bayesian-updating design: event-type base rate as prior, story-specific signal as likelihood.
- Confidence-scoring (AlphaSense) and story vs. rolling company-level aggregation (Bloomberg) suggest a production system should track both a single-event score and a decaying rolling composite per stock, not just isolated event scores.
- No vendor publishes an explicit weighting formula (e.g., w1*sentiment + w2*size + w3*surprise); all treat their composite construction as proprietary IP, calibrated empirically against historical tick/price data rather than derived from a closed-form theoretical model.

### Gaps
- Could not access the full RavenPack "Introducing RavenPack Analytics for Equities" whitepaper (referenced but not directly fetched) which likely contains more granular scoring-weight methodology — only secondary summaries were available.
- No explicit machine-learning composite scoring methodology from Bloomberg or AlphaSense was found beyond described sentiment score construction; whether/how they blend size, surprise, and sentiment into one number (vs. leaving that to the client's own model) is unclear — treat as a gap in public documentation, likely intentionally proprietary.
- Did not find a specific published example of a vendor's explicit linear-weighting or ML-weighting formula (coefficients) for combining sub-factors into one output score.

## What is known specifically about contract-announcement events (government/defense/PSU contract awards) vs. earnings vs. M&A — differences in abnormal return magnitude, reaction speed, and drift?

### Takeaway
Government/PSU contract-win announcements produce measurable but generally modest and sometimes statistically insignificant abnormal returns (roughly 0.5%–1.4% on the event day in the studies found), smaller and less consistently significant than earnings-surprise or M&A effects; reaction appears fast (consistent with market efficiency) with limited evidence located here specifically quantifying contract-announcement drift, while PEAD (earnings) and M&A drift are much more extensively documented.

### Cited Findings
- A broad study of corporate contracting found "significant average abnormal returns of 1.43% for contractors on the contract announcement day," but insignificant abnormal returns (0.03%) for the counterparty ("contractees"); for corporate-government contracts specifically, average abnormal returns for contractors were 0.54% and statistically significant — [The Valuation Effect and Determinants of Corporate Contracting, UCLA Anderson](https://www.anderson.ucla.edu/documents/areas/fac/finance/20-05.pdf) (cited via search-result summary; direct PDF fetch failed/returned unparseable binary content, so these figures should be treated as reported by secondary search summary rather than independently verified from the source text)
- A pharmaceutical-industry-specific event study (12 NASDAQ-listed pharma companies, 327 event days, 2010–2021, CAPM-based event study with a ±10 trading day window) found that "average abnormal returns within the event window were positive but not statistically significant, implying winning a government contract has a limited impact on the stock market," even though cumulative abnormal returns (CAR) across the window did show a significant positive market reaction — [The Effect of Public Contract Winning Announcements on Share Prices, Journal of Economic Analysis](https://www.anserpress.org/journal/jea/3/1/43)
- For Indian PSU/defense-adjacent order wins, only anecdotal/news-level (not peer-reviewed academic) evidence was found: e.g., BHEL's large power-project "Notification of Award" (June 2026) corresponded with the stock trading "1.74% up from its previous closing price" and RVNL's ₹132 crore Central Railway order corresponded with a roughly 2.4% intraday gain — [Zee Business, RVNL order win](https://www.zeebiz.com/markets/stocks/news-rvnl-share-price-nse-bse-multibagger-psu-stock-to-buy-rail-vikas-nigam-limited-order-win-from-indian-railway-299485); [Tradebrains, PSU power project order](https://tradebrains.in/240000-cr-order-book-psu-stock-jumps-after-securing-21000-cr-power-project-contract/)
- On earnings vs. other announcement types, market reaction speed to earnings has increased with low-latency trading: "Low latency traders trade aggressively at the time of earnings announcements, such that information in earnings surprises is quickly incorporated into prices and the post-announcement drift is reduced... Low-latency trading significantly increased the magnitude of the immediate market reaction to earnings news" — [Chordia & Miao, Market Efficiency in Real Time, MIT Sloan](https://mitsloan.mit.edu/sites/default/files/inline-files/Chordia_Miao.pdf)
- PEAD magnitude and persistence (for comparison): Bernard & Thomas (1989) found "the spread in average return between stocks in the top and bottom deciles in standardized unexpected earnings (SUE) is positive in 41 of the 48 quarters from 1974 to 1985," and drift "mostly happens in the first post-announcement quarter and attenuates rapidly afterwards" — [Wikipedia, Post-earnings-announcement drift](https://en.wikipedia.org/wiki/Post%E2%80%93earnings-announcement_drift); [PEAD review, ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2214635020303750)
- For M&A, equal-weighted acquirer announcement abnormal returns of roughly 1.1% were reported in one study, but with a documented "size effect" where dollar-value losses can still occur for large acquirers despite a positive percentage CAR; acquirer firm size was found to correlate with dollar-magnitude CAR "6 to 13 times more than... deal size" — [Firm size and gains from acquisitions](https://leeds-faculty.colorado.edu/bhagat/acquisitiongains-firmsize.pdf)

### Inferences
- Contract/PSU-order-win abnormal returns (roughly 0.5–1.5% same-day, per the two academic studies found) appear comparable in same-day magnitude to average M&A acquirer returns (~1.1%) but are reported with weaker/inconsistent statistical significance across industries — suggesting contract-win reactions are more sensitive to context (contract size relative to firm scale, buyer type, sector) than a single average figure implies, reinforcing the need for a relative-size-normalized score component rather than an absolute deal-value component.
- The near-total absence of peer-reviewed India-specific PSU/defense contract event studies in the search results (only news anecdotes found) is itself a notable finding — an Event Watcher redesign for the Indian market cannot lean on published Indian abnormal-return benchmarks and would likely need to calibrate its own historical base rates from Indian order-win data.
- Reaction speed to contract announcements was not directly quantified in the sources found (no explicit statement of "reacts within X minutes"), unlike earnings (well-documented low-latency reaction) — this is a genuine literature gap, not just a search-completeness issue, since contract-award news lacks a "scheduled announcement date" structure that most reaction-speed studies rely on (they typically study anticipated/scheduled events like earnings calendars).

### Gaps
- No peer-reviewed, India-specific (NSE/BSE) academic event study on PSU or defense contract-win announcements was found; only anecdotal news reports of single-stock price moves. This is a clear gap for the report writer to flag as "no direct academic benchmark for Indian PSU/defense contract events — would need proprietary backtesting."
- Could not directly verify the UCLA "Valuation Effect and Determinants of Corporate Contracting" paper's methodology (estimation window, market model, sample period, or whether it examines contract-size or surprise as a moderating variable) because the PDF fetch failed; figures cited are from a secondary WebSearch summary only, not independently confirmed against the source text.
- No source quantified how much faster/slower markets react to unscheduled contract-win news vs. scheduled earnings news (e.g., in minutes/hours) — flagged as an open question, not fabricated.

## What weighting or composite-scoring approaches are described in the literature or by vendors?

### Takeaway
Three broad approaches appear across sources: (1) regression-based factor decomposition in academic work (used for explaining CAR post-hoc, not real-time scoring), (2) proprietary empirically-calibrated composite indices at vendors (RavenPack CSS/ESS, Bloomberg sentiment + Market Moving News probability, AlphaSense confidence-weighted sentiment), and (3) an emerging body of ML-classifier approaches (XGBoost, random forests, deep learning) that directly predict drift continuation probability or return magnitude from multi-factor feature sets, including textual/contextual features alongside traditional numeric factors.

### Cited Findings
- Academic regression approach: earnings-surprise studies "provide a differential effect between positive and negative earnings surprises" via regression coefficients, and "the post-earnings announcement drift is larger when the earnings surprise is defined using analysts' forecast errors" rather than a pure historical/time-series benchmark — [Earnings Surprises and Stock Returns thesis summary](https://scripties.uba.uva.nl/download?fid=c2914230)
- ML classifier approach: "When properly configured using a Genetic Algorithm, XGBoost produces meaningful prediction accuracy on the direction of PEAD, with a classification success rate going up to 63%" — [Capturing dynamics of post-earnings-announcement drift using GA-optimized XGBoost, ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S095741742100333X)
- A more comprehensive supervised-learning feature set for PEAD prediction uses four categories: "textual features, contextual features, earnings features, and fundamental and technical features," and found that "contextual features provide information unexplained by earnings, fundamental and technical features, improving average returns per trade of a hypothetical long-short portfolio by 53 to 354 basis points" — [Predictability of PEAD with Textual and Contextual Factors, ACM](https://dl.acm.org/doi/fullHtml/10.1145/3604237.3626861)
- A random-forest approach to PEAD prediction uses "valuation ratios, forecast errors, forecast uncertainty, and sentiment of the earnings call" as combined inputs — [Visualizing Earnings to Predict PEAD, ResearchGate](https://www.researchgate.net/publication/386340731_Visualizing_Earnings_to_Predict_Post-Earnings_Announcement_Drift_A_Deep_Learning_Approach)
- Bayesian framing: "If both the prior belief and signal follow normal distributions, the posterior estimation also follows a normal distribution" — used in market microstructure models of investor underreaction/belief updating speed, conceptually supporting a Bayesian-updating design (event-type historical distribution as prior, new announcement's specific attributes as the signal that updates the posterior expected-return estimate) — [Bayesian Investor Belief Updating Speed, Australian Accounting Review 2023](https://onlinelibrary.wiley.com/doi/full/10.1111/auar.12395)
- Event-type-conditional modeling outperforms uniform treatment: heterogeneity in CAR distribution "dispersion and tail behavior among event types" supports building separate expected-return priors per event category rather than one global score — [Janus-Q, arXiv 2602.19919](https://arxiv.org/pdf/2602.19919)
- Volume confirmation as a weighting input: "a drift backed by abnormal volume is more durable than one on thin trading" — suggested as a practical filter/weight on top of a base sentiment or surprise score — [EventStudyTools, Event Studies for Investment Strategies](https://www.eventstudytools.com/investment-strategies)

### Inferences
- No source describes a simple, fully disclosed linear weighted-sum formula (e.g., Score = w1·Surprise + w2·Size + w3·Sentiment) used in production by a named vendor; all production-grade systems found either (a) keep exact weights proprietary (RavenPack/Bloomberg/AlphaSense) or (b) use non-linear ML models (XGBoost/random forest/deep learning) rather than a hand-set linear formula. This suggests that for the Event Watcher redesign, a transparent linear composite (for interpretability/debuggability) is a legitimate design choice not because it's what vendors do, but because it trades some predictive power for interpretability — this is a design trade-off to make explicitly, not something the literature mandates either way.
- A hybrid Bayesian design is well supported conceptually: use event-type historical CAR/win-rate distribution as a prior (calibrated from the module's own historical Event Watcher outcomes), and adjust with a likelihood term from the specific event's attributes (relative size, surprise magnitude, sentiment/NLP score, volume confirmation) — this maps cleanly onto both the academic Bayesian-updating literature and the practical "rank cross-section, compare CAAR trajectories" prototyping approach found in the EventStudyTools source.

### Gaps
- No explicit disclosed weighting scheme (numeric coefficients) from any vendor was found; this appears to be genuinely proprietary/undisclosed information industry-wide, not a search shortfall.
- Could not find literature specifically on weighting schemes for **government contract-award** signal scores (as opposed to earnings/M&A); this is an extrapolation gap — the composite-scoring approaches found are drawn from earnings/M&A/general news-sentiment literature and applied here as an analogy, since contract-specific composite-scoring literature does not appear to exist publicly.
